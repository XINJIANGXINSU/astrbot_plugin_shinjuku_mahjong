# 新宿日麻（astrbot_plugin_shinjuku_mahjong）

群聊四人日麻辅助插件。视觉 LLM 从整桌照片中识别和牌区域，再由确定性计分代码按照雀魂常规四麻规则计算番、符和点数；用户确认后才写入四名玩家的牌桌记录。

## 使用方法

开桌时按东、南、西、北顺序艾特四名玩家：

```text
@机器人 麻 开桌 @玩家1 @玩家2 @玩家3 @玩家4
```

荣和：

```text
@机器人 麻 @和牌者 荣和 @放铳者 东1局 0本场 立直
[整桌和牌照片]
```

自摸：

```text
@机器人 麻 @和牌者 自摸 东1局 0本场
[整桌和牌照片]
```

识别并计算完成后，插件只生成待确认记录：

```text
麻确认   写入本局点数
麻取消   放弃待确认记录
麻查询   查看四名玩家当前点数
麻撤销   撤销上一条已确认记录
麻结束   显示最终点数并关闭牌桌
麻帮助   显示使用说明
```

## 拍照要求

- 和牌者的牌完整摊开，和牌张应单独放置或与手牌有明显间隔；
- 副露、暗杠和宝牌指示牌区域不能被遮挡；
- 尽量从桌面正上方拍摄，避免反光、模糊和裁切；
- 其他玩家不要同时把手牌混入和牌区域；
- 识别置信度不足或存在无法确认的牌时，插件拒绝进入记账。

立直、一发、岭上、抢杠、海底、河底、天和、地和等通常无法仅由最终桌面照片证明，必须写在申报文字中。

## 规则

- 四人日麻，默认每人 25000 点；
- 食断、赤宝牌、双倍役满启用；
- 累计役满上限为单倍役满；
- 不采用切上满贯；
- 按当前局数自动确定庄家和玩家自风；
- 本场计入得点；立直棒的自动扣除与累计将在后续版本补充。

## 配置项

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| `enabled` | `true` | 是否启用插件 |
| `initial_points` | `25000` | 开桌时每名玩家的初始点数 |
| `use_shinjuku_user_database` | `true` | 是否使用新宿主插件用户数据库；开启后四名玩家必须已注册，段位可在 `/背包` 查看 |
| `shinjuku_database_path` | 空 | 主插件使用自定义数据库路径时，在这里填写相同的绝对路径 |
| `vision_confidence_threshold` | `0.85` | 图片识别结果进入计分的最低置信度 |

## 新宿用户数据库联动

联动默认开启。插件会在新宿主插件的数据库中新增独立的 `MahjongRank` 和 `MahjongMatch` 表，不修改现有用户、资产和计费数据。玩家通过 QQ 绑定关联到新宿用户；牌桌结束后，主插件 `/背包`会显示日麻段位、段位分、Rate、总对局数和平均顺位。

关闭联动后，段位写入本插件数据目录下的 `mahjong_rank.db`，不要求玩家注册新宿用户，但主插件 `/背包`无法显示这套独立段位。

## 模型要求

当前会话使用的 LLM 必须支持图片输入。插件同时注册 `shinjuku_mahjong` LLM Tool；带“麻”的群聊消息也会由插件直接接管，以保证算分请求不会因模型未主动调用工具而遗漏。
